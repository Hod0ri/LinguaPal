📖 단어 관리

단어 목록 조회

GET /api/v1/admin/words

단어 상세 조회

GET /api/v1/admin/words/{id}

단어 생성

POST /api/v1/admin/words/create

단어 수정

PATCH /api/v1/admin/words/{id}/update

단어 삭제

DELETE /api/v1/admin/words/{id}/delete

🌐 단어 번역 관리

번역 목록 조회

GET /api/v1/admin/words/{word_id}/translations

번역 추가

POST /api/v1/admin/words/{word_id}/translations/create

번역 수정

PATCH /api/v1/admin/words/{word_id}/translations/{translation_id}/update

번역 삭제

DELETE /api/v1/admin/words/{word_id}/translations/{translation_id}/delete

📝 예문 관리

예문 목록 조회

GET /api/v1/admin/words/{word_id}/examples

예문 추가

POST /api/v1/admin/words/{word_id}/examples/create

예문을 입력하면 미리보기가 표시됩니다

예문 수정

PATCH /api/v1/admin/words/{word_id}/examples/{example_id}/update

예문 삭제

DELETE /api/v1/admin/words/{word_id}/examples/{example_id}/delete

예문 번역 추가

POST /api/v1/admin/words/{word_id}/examples/{example_id}/translations/create
